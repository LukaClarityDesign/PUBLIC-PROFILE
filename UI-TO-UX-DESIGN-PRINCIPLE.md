# UI-to-UX Design Principle

## The interface is not the experience

A user interface is one part of a product. The user experience emerges from the complete journey: understanding, expectations, decisions, interactions, feedback and outcomes.

Good UI work should therefore support a coherent UX rather than optimize isolated screens.

### Principles

1. **Start with the user's goal.** Understand what the person is trying to accomplish before deciding what the interface should look like.
2. **Make structure visible.** Information hierarchy, navigation and system status should be understandable.
3. **Reduce cognitive friction.** Avoid unnecessary choices, ambiguous labels and interactions that require users to guess.
4. **Make feedback meaningful.** Every important action should produce clear, timely and appropriate feedback.
5. **Design the whole journey.** Consider entry points, errors, empty states, recovery and completion—not only the ideal path.
6. **Keep visual decisions functional.** Typography, color, spacing, motion and imagery should improve comprehension and usability.
7. **Validate with evidence.** Evaluate the experience through observation, testing and real usage where possible.

**In short:** UI is what people interact with; UX is how the entire product works for them. The interface should make the experience clearer, not merely make the screen look finished.
